OpenProxyTools

OpenProxyTools is an open-source Python tool that can be used to test HTTP and HTTPS proxies.

The tool verifies if the proxies can establish connections to the test URL and evaluates their approximate response time.

Features

- Verify HTTP/HTTPS proxies’ connectivity
- Evaluate their approximate response time
- Test several proxies simultaneously
- Export the results to JSON format
- Lightweight and easy-to-use

Installation

Download the repository:

git clone https://github.com/HighlightJbl/OpenProxyTools.git
cd OpenProxyTools
